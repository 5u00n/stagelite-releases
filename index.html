First-Run & Installation Notes

🍏 macOS Gatekeeper Note (Unsigned / Ad-Hoc Build)

Because Stagelite is distributed directly without the Mac App Store, macOS may show a prompt: "Stagelite cannot be opened because Apple cannot check it for malicious software".

To open: Go to System Settings > Privacy & Security, scroll down, and click Open Anyway. Alternatively, run this in Terminal: xattr -cr /Applications/Stagelite.app

🪟 Windows SmartScreen Notice

On Windows 10/11, Windows SmartScreen may show "Windows protected your PC" on brand-new builds. Click More info and then click Run anyway.

🐧 Linux AppImage Execution

Make sure to grant executable permissions before launching: chmod +x Stagelite-Linux-x64.AppImage
